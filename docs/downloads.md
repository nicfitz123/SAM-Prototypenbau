# Downloads

## Verfuegbare Planungsdokumente

Die folgenden Dateien bilden die Arbeitsgrundlage der Unterrichtsplanung:

- `Unterrichtsplan`
- `Verzahnte Jahresplanung`
- `Projektliste und Kompetenzmatrix`
- `Masterplanung`

## Vorschlag fuer die Bereitstellung

Sobald die Dateien im Repository oeffentlich liegen, koennen sie hier verlinkt werden, zum Beispiel:

- [Unterrichtsplan](https://github.com/nicfitz123/SAM-Prototypenbau/blob/main/Aktuell/Planung/Unterrichtsplan_Prototypenbau_1_und_2_Klasse.md)

## Spaeter sinnvoll ergaenzbar

- Materiallisten pro Projektblock
- Bewertungsraster pro Projekt
- Arbeitsblaetter
- Sicherheitsunterlagen
- Projektfotos
- Beispiel-Dokumentationen von Schuelerprojekten

## Hinweis

Wenn du die Seite spaeter oeffentlich nutzt, solltest du nur solche Unterlagen verlinken, die du auch wirklich veroeffentlichen moechtest.
Fuer interne Dokumente oder Schuelerarbeiten ist eine geschuetzte Plattform wie `Moodle` besser geeignet.
